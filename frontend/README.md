# 🚀 DevCollab

A full-stack MERN web application that helps developers discover projects, collaborate with teammates, and build meaningful connections.

---

## 📖 About

DevCollab is a collaborative platform where developers can:

- 👤 Create and manage their profiles
- 💼 Showcase technical skills and projects
- 🤝 Connect with other developers
- 📩 Send and accept collaboration requests
- 📢 Receive real-time notifications
- 🚀 Create, join, and manage development projects

This project is built using the **MERN Stack** with a modern, responsive user interface.

---

## ✨ Features

### 🔐 Authentication
- User Registration
- Secure Login
- JWT Authentication
- Password Encryption using bcrypt

### 👤 User Profile
- Edit Profile
- Upload Profile Picture
- Cover Image
- Bio & Skills
- Location

### 🤝 Connections
- Send Connection Requests
- Accept/Reject Requests
- View Connected Developers

### 💻 Project Management
- Create Projects
- Join Projects
- View All Projects
- Project Categories
- Difficulty Levels
- Team Size
- Progress Tracking

### 🔔 Notifications
- Collaboration Notifications
- Connection Request Notifications
- Mark Notifications as Read

### 🎨 User Interface
- Responsive Design
- Modern Dashboard
- Clean Navigation
- Interactive Cards

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/DevCollab.git
```

### Navigate into the project

```bash
cd DevCollab
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```
